# Бот заказа песен — шаблон (ARCANE)

Мини-апп в Telegram: гость выбирает песню из репертуара, пишет поздравление,
артисту в Telegram приходит заказ, гость уходит на оплату.

## Сайт и бот — одно и то же

Это одна страница. В Telegram она открывается из бота как мини-апп, в браузере —
как обычный сайт по адресу Vercel. На сайте гостя дополнительно просят оставить
телефон или ник для связи (в Telegram он и так известен), а если в `config.js`
задан `botUsername`, внизу появляется кнопка «Открыть в Telegram».

## Что где

| Файл | Что в нём |
|---|---|
| `public/config.js` | ВСЁ, что отличает артиста: имя, цена, ссылка на оплату, расписание, соцсети, фото, репертуар |
| `public/photos/` | фото: `hero.jpg` — шапка, остальные — для вкладки «Фото» (перечислить в `config.js` → `photos`) |
| `public/index.html` | страница (палитра — переменные `:root` в начале) |
| `api/notify.js` | заказ → сообщение артисту |
| `api/webhook.js` | ответ бота на /start с кнопкой |

Новый артист = скопировать репозиторий, поменять `config.js` и фото.

## Запуск (бесплатно: GitHub + Vercel)

GitHub Pages не подходит: он отдаёт только статику, а токен бота нельзя
класть в страницу. Vercel бесплатно берёт этот же репозиторий с GitHub,
запускает папку `api` и даёт адрес вида `имя.vercel.app` — свой домен не нужен,
Telegram открывает мини-апп по любому https-адресу.

1. **Бот.** В @BotFather: `/newbot` → получить токен.
2. **Чей чат получает заказы.** Узнать свой chat id (например, у @userinfobot).
3. **Vercel.** vercel.com → войти через GitHub → Add New → Project → выбрать
   этот репозиторий → Deploy. В Settings → Environment Variables добавить:
   - `BOT_TOKEN` — токен бота;
   - `OWNER_CHAT_ID` — chat id из шага 2;
   После добавления переменных — Deployments → Redeploy.
4. **Подключить бота к сайту.** Открыть в браузере `<АДРЕС>/api/setup`
   (например `https://arcane-bot-gamma.vercel.app/api/setup`). Страница сама
   поставит вебхук и кнопку меню, токен вручную вставлять не нужно.

Дальше любая правка в GitHub (`config.js`, фото) сама выкладывается на Vercel.

## Оплата

`paymentUrl` в `config.js` — ссылка на Яндекс Чаевые или другой сервис.
Пусто — после заказа гость видит «Заказ отправлен», оплату артист просит сам.
Сервис не знает, прошла ли оплата: в уведомлении написано «проверьте, пришла ли оплата».
